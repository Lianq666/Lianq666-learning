# 密码机小游戏

一个无需联网的 Windows 桌面益智小游戏。玩法参考“计客超级密码机”：猜出隐藏的颜色密码，并利用每轮提示逐步排除错误答案。

## 项目说明（Specification）

### 项目目标

做一款操作简单、界面简约的单人解谜小游戏，让玩家通过逻辑推理破解随机生成的颜色密码。

### 功能需求

- 两种游戏模式：单人闯关（机器随机出题，逐关加难）与限时挑战（默认 60 秒，连续答题计分）。
- 三档预设难度：简单、标准、困难；也可以自行设置密码位数、可用颜色数、机会数和限时时长。
- 首次启动会显示三步玩法教学；右上方“教学”按钮可以随时重看。
- 每轮记录采用实心/空心小圆点阵列：实心表示颜色和位置都正确，空心表示颜色正确但位置不同。
- 本地保存最高闯关、限时最高分、累计破解数和成就；点击“我的记录”即可查看。
- 点击颜色即可填入当前空位；可清空本轮，或提交本轮猜测。
- 每轮给出两类反馈：
  - **黑点**：颜色与位置都正确。
  - **白点**：颜色正确，但位置不对。
- 显示剩余机会、已用时间与历史猜测；游戏结束自动揭示答案。
- 单击“新游戏”可立即重新开始。

### 非功能需求

- 游戏运行时仅使用 Python 自带的 `tkinter`，不联网，不收集数据。
- 提供独立 `.exe` 打包版，适配 Windows 常见桌面环境。
- 已开启 Windows 高 DPI 屏幕适配：在 125%、150% 等显示缩放下，文字和色块会按真实像素清晰绘制。
- 采用纯色色块操作，保持界面简约；密码答案也会以色块形式展示。

### 本地数据说明

游戏仅在本机保存下列数据：最高闯关、限时最高分、累计破解数、已解锁成就和是否看过教学。默认保存到：

`%LOCALAPPDATA%\密码机小游戏\progress.json`

不保存账号、密码、网络信息或任何个人资料。删除该文件即可清空游戏记录。

### 技术架构

`game.py` 分为两部分：

1. **游戏规则层**：`score_guess()` 计算黑点与白点，可单独测试。
2. **界面层**：`PasswordMachineApp` 负责按钮、棋盘、计时和设置窗口。

### 文件结构


### 开发计划与验收标准

| 阶段 | 内容 | 验收标准 |

| 1 | 规则与难度设计 | 能描述两类提示和三档难度 |
| 2 | 实现桌面界面 | 可以选择颜色、清空、提交和重开 |

## 怎么运行

1. 优先双击 `release` 文件夹中的 `密码机小游戏.exe`；如果尚未生成 `.exe`，双击 `run_game.bat`。
2. 在游戏窗口上方选择“单人闯关”或“限时挑战”，再选择起始难度，或点击“自定义设置”。
3. 从颜色按钮中逐个点击，填满当前一排。
4. 点击“提交猜测”，再根据黑点、白点调整下一排。

## 注意事项

- 修改“自定义设置”后会自动开始新的一局，当前进度会丢失。
- 单人闯关每通过两关会增加一个密码位、每通过三关会多一种可用颜色；限时挑战答错次数用完后会直接换下一题。
- `.exe` 是单文件程序，首次启动可能比脚本版慢几秒，这是正常的解包过程。
- 颜色允许重复，这是此类密码机的经典规则；黑、白提示不会按位置排列，以免泄露额外信息。
- 如果双击后窗口没有出现，请右键该文件夹空白处，选择“在终端中打开”，执行：`python game.py`。

## 成功标志

- 窗口标题显示“密码机”。
- 点击颜色后，当前猜测区出现对应色块。
- 提交后会新增一条历史记录，并显示实心/空心提示圆点；重开游戏后“我的记录”中的成绩仍会保留。

## 给学习者的小提示

先用一轮测试尽可能多的不同颜色，确定哪些颜色存在；再用下一轮交换这些颜色的位置，就能把“颜色是否存在”和“位置是否正确”分开推理。这就是把复杂问题拆成小问题的工程思维。
